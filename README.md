# Vue.js Training Course - CCEO

This repository contains the code, exercises, notes, and projects developed throughout the **Vue.js training course provided by CCEO**.

The purpose of this repository is to serve as a **learning log and technical reference**, documenting progress over time as new topics, best practices, and project implementations are added.

---

## 📚 About This Repository

This project is intended to grow progressively during the training process.

As the course advances, this repository will include:

- Fundamental Vue.js concepts
- Component-based architecture examples
- State management practices
- Routing implementations
- Reusable UI components
- Best practices and coding standards
- Real-world mini projects
- Personal notes and learnings

This makes the repository not only a code base, but also a **knowledge base** for future reference.

---

## 🛠 Technologies

Currently used technologies:

- **Vue.js**

- **HTML5**
- **CSS3**

- Vue Router

- Testing tools
